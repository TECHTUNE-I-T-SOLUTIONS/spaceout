## 🌟 About SpaceOut

**SpaceOut** is a modern, premium workspace and technology hub designed for professionals who demand more from their environment. We provide reliable infrastructure—including stable power and high-speed internet—along with a thriving community. 

In addition to physical coworking solutions, **SpaceOut Tech** (our learning arm) provides hands-on, practical technology bootcamps for kids, teens, and adults looking to build real-world skills.

## 🛠️ Technology Stack

Our platform is built with modern web technologies to ensure a fast, responsive, and secure experience:

- **Frontend:** Next.js (App Router), React, TypeScript
- **Styling:** Tailwind CSS, Framer Motion (for fluid animations and transitions)
- **UI Components:** Radix UI / shadcn/ui for accessible, interactive elements
- **Authentication:** NextAuth.js
- **Database:** MongoDB (via Mongoose)
- **Icons:** Lucide React

## 🚀 Getting Started

To run the SpaceOut platform locally:

1. **Clone the repository**
   ```bash
   git clone https://github.com/TECHTUNE-I-T-SOLUTIONS/spaceout.git
   cd spaceout
   ```

2. **Install dependencies**
   ```bash
   pnpm install
   ```

3. **Set up Environment Variables**
   Create a `.env.local` file based on `.env.example` and add your MongoDB URI, NextAuth secrets, etc.

4. **Start the Development Server**
   ```bash
   pnpm dev
   ```
   *Visit `http://localhost:3000` to view the application.*
